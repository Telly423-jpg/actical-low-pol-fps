# actical-low-pol-fps
🎮 战术竞技场 3D (Tactical Low-Poly FPS) 一键部署、零服务器门槛、纯粹硬核的 Web 3D 多人联机第一人称射击游戏！
🌟 游戏特色
零后端，真正免部署开黑：基于先进的 WebRTC (PeerJS) 点对点 P2P 技术构建。只需将单文件代码托管至 GitHub Pages，即可随时随地与好友通过浏览器开启跨设备实时对战，无需配置任何复杂的 Node.js 后端服务器！

硬派低多边形（Low-Poly）战术美学：告别单调的塑料感和简陋模型。游戏拥有硬朗的战术方块躯干、标准战术头盔与发光护目镜面罩，搭配精细的 PBR 材质枪械与多层次光影，完美还原高品质 Roblox 竞技游戏的视觉风格。

爽快流畅的 FPS 竞技体验：

内置精密的鼠标锁定第一人称视角（PointerLockControls）、WASD 战术移动与重力跳跃物理系统。

真实高效的射线检测（Raycasting）命中判定、动态弹道特效与受击红屏血雾反馈。

完整的战术生死循环：支持实时在线人数统计、动态击杀播报（Kill Feed）。当玩家不幸阵亡时，模型将完美隐形，并在专属的重生过渡界面等待 2 秒后，重新部署于地图中的随机安全出生点，仪式感与节奏感拉满！

🕹️ 游玩指南
创建房间：打开游戏页面，等待状态显示“房间已就绪”，点击 复制房间 ID 发送给好友。

加入战斗：好友打开链接后，输入你的房间 ID 点击 加入战斗。

锁定与射击：当在线人数大于等于 2 时，点击屏幕任意位置锁定鼠标视角，即可使用 WASD 移动、空格 跳跃、鼠标左键 举枪射击！
